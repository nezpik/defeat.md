# defeat.md

[![skills.sh](https://skills.sh/b/nezpik/defeat.md)](https://skills.sh/nezpik/defeat.md)

`defeat.md` is an MIT-licensed Agent Skill and reference document for helping AI agents recognize defeat as both a human feeling and a real-world situation.

It is designed for agents working with people, teams, projects, and enterprises where defeat may be present but denied, minimized, mislabeled, or converted into pressure to continue.

## Purpose

AI agents are often optimized to continue: plan, motivate, rewrite, accelerate, and solve. In some situations, continuing under the same assumptions causes harm. This repository gives agents language and procedure for recognizing when a person, team, project, strategy, or organization may be defeated and needs truth, dignity, de-escalation, or escalation rather than more optimization.

## Files

- `Defeat.md`: The full perspective document.
- `defeat/SKILL.md`: Agent Skills-compatible instruction file.
- `LICENSE`: MIT license.

## Skill usage

The skill lives in:

```text
defeat/SKILL.md
```

This follows the Agent Skills convention where a skill is a folder containing a `SKILL.md` file with YAML frontmatter.

## When agents should use this

Use this skill when a user, team, or enterprise context suggests defeat, denial, hopelessness, exhausted capacity, impossible delivery, failed strategy, hidden bad news, forced optimism, or escalation of commitment.

Do not use it as a replacement for clinical care, legal advice, HR process, safety response, or executive accountability.
